## 🚀 Getting Started

### Prerequisites
Node.js 18+ and npm installed on your machine.

### Installation
```bash
# Clone the repository
git clone https://github.com/Martish-cloud/Bloom-Beauty_Cosmetics.git
cd Bloom-Beauty_Cosmetics

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:5173` in your browser.

### Production Build
```bash
npm run build
npm run preview
```
